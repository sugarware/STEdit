# STEdit
Simple Text Editor

テキストエディタです  
基本的な機能と快適さに拘りました  
  
メニューのボタンはタップ、ダブルタップ、長押し、と機能も階層化されて覚えやすい  
  
* undo,redo
* 2つのペーン(本文、検索結果)
* 検索と置換
* ~~階層範囲でのAND検索……
* 可変文字サイズ
* 
* PWA対応で、通常アプリっぽく使える

## [ここから実行出来ます！🚀](https://sugarware.github.io/STEdit)

実行後にブラウザのメニューから「ホーム画面に追加」を選べば、アプリっぽく使えます  
その後はブラウザの内部メモリに登録されるので、オフラインでも起動できます
